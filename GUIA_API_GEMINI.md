# 🤖 Guía Completa: Cómo Obtener tu API Key de Google Gemini (GRATIS)

## 📋 Resumen Rápido

Google Gemini ofrece una API **completamente gratuita** con límites generosos:
- ✅ **60 solicitudes por minuto**
- ✅ **1,500 solicitudes por día**
- ✅ **Sin tarjeta de crédito requerida**
- ✅ **Modelo Gemini 1.5 Flash** (rápido y eficiente)

## 🚀 Pasos para Obtener tu API Key

### Paso 1: Ir a Google AI Studio
1. Abre tu navegador
2. Ve a: **https://aistudio.google.com/app/apikey**
3. Inicia sesión con tu cuenta de Google (Gmail)

### Paso 2: Crear tu API Key
1. Haz clic en el botón **"Create API Key"** (Crear clave de API)
2. Selecciona un proyecto de Google Cloud o crea uno nuevo:
   - Si no tienes proyecto: Haz clic en **"Create API key in new project"**
   - Si ya tienes proyecto: Selecciónalo de la lista
3. Espera unos segundos mientras se genera tu clave

### Paso 3: Copiar tu API Key
1. Verás tu API key en formato: `AIzaSy...` (empieza con "AIzaSy")
2. Haz clic en el botón **"Copy"** (Copiar) 📋
3. **¡IMPORTANTE!** Guarda esta clave en un lugar seguro

### Paso 4: Configurar en el Simulador
1. Abre el simulador de regresión lineal
2. Ve a la página **"Asistente IA"** (icono de chat en el menú)
3. En la sección **"Configuración"**:
   - **Proveedor**: Selecciona "Google Gemini"
   - **API Key**: Pega tu clave (Ctrl+V)
4. Haz clic en **"Guardar"**
5. ¡Listo! Ya puedes hacer preguntas

## 🔒 Seguridad de tu API Key

### ✅ Buenas prácticas:
- Tu API key se guarda **solo en tu navegador** (localStorage)
- No se envía a ningún servidor externo (excepto Google)
- Puedes borrarla en cualquier momento

### ⚠️ Nunca compartas tu API key:
- No la publiques en redes sociales
- No la subas a GitHub o repositorios públicos
- No la compartas con desconocidos

### 🔄 Si crees que tu clave fue comprometida:
1. Ve a https://aistudio.google.com/app/apikey
2. Haz clic en el ícono de **basura** 🗑️ junto a tu clave
3. Crea una nueva clave

## ❓ Solución de Problemas

### Error: "API_KEY_INVALID"
**Causa**: La clave no es válida o está mal copiada
**Solución**:
1. Verifica que copiaste la clave completa (empieza con "AIzaSy")
2. No debe tener espacios al inicio o final
3. Genera una nueva clave si es necesario

### Error: "QUOTA_EXCEEDED"
**Causa**: Superaste el límite de 60 solicitudes por minuto
**Solución**:
- Espera 1 minuto antes de hacer más preguntas
- Reduce la frecuencia de consultas

### Error: "Failed to fetch"
**Causa**: Problema de conexión a internet
**Solución**:
- Verifica tu conexión a internet
- Intenta recargar la página
- Desactiva VPN o proxy si los usas

### El chatbot no responde
**Solución**:
1. Verifica que guardaste la API key
2. Abre la consola del navegador (F12) y busca errores
3. Recarga la página (F5)
4. Intenta con una pregunta más simple
